The extension only supports Chromium browsers.

To install this extension:
1. Click "Code" and then "Download ZIP"
2. Extract in a folder
3. Open the Chromium browser of your choice and in the url bar enter "{Your Browser Name}://extensions", for example "chrome://extensions"
5. Look for the "Developer mode" toggle and turn it On.
6. Click "Load unpacked" and select the "sticky-browser-extension" folder you got after extracting the ZIP file.
7. Load it up and you have the extension in your browser.
