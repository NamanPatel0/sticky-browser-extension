The extension only supports Chromium browsers.

To install this extension:
1. Click "Code" and then "Download ZIP"
   <img alt="image" src="https://github.com/user-attachments/assets/02b33113-0344-4381-a504-bae9ffd7ba99" />
   
2. Extract in a folder
3. Open the Chromium browser of your choice and in the url bar enter :
   "{Your Browser Name}://extensions" for eg. "chrome://extensions"
4. Look for the "Developer mode" toggle and turn it On.
5. Click "Load unpacked" and select the "sticky-browser-extension" folder you got after extracting the ZIP file.
6. Load it up and you have the extension in your browser.
